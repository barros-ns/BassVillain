FERRAMENTAS (nao fazem parte do jogo, so geram os mapas)

gerar_mapa.py     Cria os mapas .json de uma musica a partir das notas reais do baixo do mp3.
analise_baixo.py  Detecta o ataque (ms) e a altura de cada nota do baixo.

Precisa de: python3, numpy, scipy e ffmpeg no PATH.

  python gerar_mapa.py DarkNecessities --relatorio   compara o mapa atual com as notas do baixo
  python gerar_mapa.py DarkNecessities               gera Facil/Medio/Dificil (sobrescreve os .json)

Ajustes (topo do gerar_mapa.py):
  GAPS        intervalo minimo entre notas por dificuldade (menor = mais notas)
  PRIMEIRA_NOTA_MS   as notas levam 1500 ms para cair, entao nao comecam antes disso

Regra das pistas: nota mais grave que as vizinhas (+-2,5 s) vai para a esquerda, mais aguda
para a direita; a mesma altura cai sempre na mesma pista. Mais de 6 notas iguais seguidas
viram um "galope" (a cada 4 notas, uma sobe uma pista), como nas partes repetidas do Barracuda.
